# Атласы модульного робота

Исходник — `art/robots/white_sets/main_robot.aseprite`. Состав соответствует слоям в этом файле. Все ячейки — 112×112, 1×, с прозрачностью и общим началом координат в левом верхнем углу.

| Атлас | Сетка | Содержимое |
|---|---|---|
| `legs.png` | 5 × 3 | Строка на ходовую. Слева `idle`, затем четыре кадра `walk` по 125 мс. |
| `body.png` | 4 × 1 | Четыре корпуса по порядку слоёв Aseprite. |
| `head.png` | 2 × 1 | Две головы по порядку слоёв Aseprite. |
| `left_tool.png` | 6 × 1 | `idle`, затем пять кадров `left_pulse` длительностью 90, 55, 55, 70 и 70 мс. |
| `right_tool.png` | 2 × 4 | Строка на руку. Слева `Upper_Arm`, справа `Forearm`. |

`robot_atlas.json` содержит идентификаторы слоёв, прямоугольники ячеек, длительности, порядок отрисовки, комплект по умолчанию и координаты шарниров. Индексы кадров внутри клипа начинаются с нуля. Поле `source_frame` использует нумерацию Aseprite с единицы. Момент импульса — индекс 1 в `left_pulse`, через 90 мс после начала.

## Назначение ресурсов в Godot

- Ноги и левая рука получают свои `SpriteFrames` из `modules/legs` и `modules/left_tool`. Включайте `walk` у ног и `left_pulse` у руки независимо.
- Корпус, голова и две части правой руки получают `AtlasTexture` из соответствующих каталогов `modules`.
- Для спрайтов с общим началом координат используйте `centered = false`. Ноги рисуются первыми, затем корпус, голова, левая и правая руки. Если корень визуала соответствует земле, сместите начало холста на отрицательный `ground_anchor` выбранной ходовой. Эта точка рассчитана по нижней границе стойки и применяется ко всему комплекту.
- Плечо правой руки находится в `mounts.right_shoulder`. Положение дочернего локтя — `elbow - right_shoulder`. Для полных текстур 112×112 задайте смещения рисунка плеча и предплечья на отрицательные координаты их шарниров в холсте. При смене правой руки берите обе текстуры и локоть из одной записи `modules.right_tool`.
